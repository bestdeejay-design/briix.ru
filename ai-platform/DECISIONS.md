# Журнал решений этапа AI-платформа

Формат как в ai-platform-docs/DECISIONS.md. Продуктовые решения арены (DEC-001 и предположения README) не дублируются — они канон.

## DEC-E01 — Прототип строится на email+пароль, recovery по email

- **Дата:** 2026-11-06 · **Статус:** принято координатором
- Закрывает R2 аудита для прототипа: единая схема входа, без варианта invite-only. Для прод-фазы решение перепроверяется по AUTH_SECURITY §1.

## DEC-E02 — Штаб этапа — репозиторий bestdeejay-design/briix.ru

- **Дата:** 2026-11-06 · **Статус:** принято владельцем
- Спеки/аудиты/доки этапа живут здесь (`ai-platform/`), код прототипа — в отдельном монорепо `bestdeejay-design/ai-platform`, создаваемом задачей этапа. Не в `test` (песочница) и не в коде сайта briix.

## DEC-E03 — Idempotency-Key в прототипе: опционален, дедупликация на адаптере

- **Дата:** 2026-11-06 · **Статус:** рабочее, до публичного контракта
- Закрывает R3 для прототипа: заголовок принимается, повтор с тем же ключом на mock-адаптере возвращает кэшированный результат и не пишет второй UsageEvent. Финальная семантика — отдельное решение перед публичным API.

## DEC-E04 — Цены в прототипе: source=manual

- **Дата:** 2026-11-06 · **Статус:** принято координатором
- Закрывает R4: цена модели — вручную заданное поле каталога без автоподсчёта от cost basis; cost basis и наценка DEC-001 появятся в фазе 2.
