# BRIIX — аудиты и ревью

Каталог следов аудитов, ревью и контрольных проверок проекта BRIIX.

## Назначение

Здесь фиксируются результаты работы агентов контроля и ревьюеров: проверки документов, ревью кода, аудиты безопасности, вычитка контрактов, отчёты о качестве. Каждый аудит — отдельный файл с датой и областью проверки.

## Формат

Рекомендуемое имя файла: `YYYY-MM-DD-<область>-<тип>.md`
Примеры: `2026-10-15-docs-review.md`, `2026-10-20-briix-md-audit.md`.

## Структура отчёта

- **Область** — что проверялось (документ / модуль / артефакт).
- **Проверяющий** — агент или роль.
- **Дата** — когда выполнен аудит.
- **Находки** — обнаруженные проблемы, несоответствия, риски.
- **Вердикт** — pass / fail / needs-changes.
- **Рекомендации** — что исправить.
