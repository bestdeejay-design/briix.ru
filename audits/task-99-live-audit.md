## Находки

1. **[МАЖОР стенда, вне ветки] BFF отклоняет инструментал с `params.model`.** Прямой сабмит
   `{type:'music', params:{model:'ace-step-flash', instrumental:true}}` → HTTP 400
   `bad_params: "params.lyrics обязателен для vocal"`; то же с `ace-step-pro`. При этом
   `{instrumental:true}` **без** `model` → 202, джоба создана и доведена до готовности.
   Клиент (и main, и ветка) всегда шлёт `model` при музыкальной генерации — т.е. генерация
   инструментала из UI на стенде сейчас не работает вообще, независимо от PR #99. Ошибка
   валидации bff, в инфраструктурный контур (infra/media-bff), к ветке отношения не имеет.
2. **[МИНОР] Клик-механика аудита:** штатные playwright-локаторы кликов по кнопкам действий
   в IAB-браузере периодически зависали на actionability; клики доводились dispatch-ом
   `el.click()` по тому же элементу (обработчик тот же). На поведение приложения не влияет,
   отмечено как ограничение среды аудита.
3. **[НАБЛЮДЕНИЕ] Ленивая загрузка библиотеки** на проде требует реального скролла карточек во
   вьюпорт (IntersectionObserver); в фоновой вкладке не срабатывает. Это дизайн main, к PR не
   относится.
