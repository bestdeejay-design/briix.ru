## Что сделано

1. **Гейт входа (клиентский, переезд на серверную auth — infra#78 без смены UI):**
   экран ник + PIN-пад (0–9, ⌫, точки состояния), 4–6 цифр; новый ник регистрируется
   при первом входе; PIN хранится только как SHA-256(nick::pin) — открытым текстом
   никогда; 5 неверных попыток → пауза 30 с; сессия живёт в localStorage (перезагрузка
   — сразу в студию); чип с ником в тулбаре = выход (confirm).
2. **Вкладки Чат / Библиотека** внизу (как в мессенджерах): в библиотеке композер
   скрыт, лента чата возвращается по вкладке «Чат».
3. **Библиотека (клиентская, переезд на GET /jobs — infra#77 без смены UI):**
   каждая успешная генерация (фото/трек) попадает в список профиля
   (`briix-studio-library-<ник>`: job_id, тип, промпт, модель, длительность, дата,
   избранное). Карточка: превью/плеер (файл дозабирается с шины по `/files/{id}`
   через Bearer, blob кешируется), ⬇ Скачать, ☆/★ В избранное, 🗑 Удалить (confirm;
   из библиотеки — файл на стенде остаётся, это честно сказано в диалоге).
   Фильтры: Все / Фото / Музыка / ★ Избранное.
4. **CSS:** .gate/.pinpad/.pin-dots/.tabs/.lib-* — только существующими токенами
   палитры, новых цветов нет; `[hidden]{display:none!important}` не нарушен.
5. **Сюита 16 → 18 секций:** гейт (вход/регистрация/перезагрузка/выход/неверный
   PIN) и библиотека (попадание джобы, фильтры, избранное, удаление, вкладки);
   `page()` получила параметр `user` (сессия v3 предзадаётся, иначе гейт); замер
   мобайла теперь меряет низ вкладок (композер+вкладки прижаты к низу).
