# Отчёт: UI-демо помощников BRIIX

**Дата:** 2026-11-06  
**Задача:** переработать корневое демо в пользовательский интерфейс с выбором помощника, примерами и полным набором локальных состояний — без backend.

## Что сделано

- Корень заменён с демо API-кабинета на пространство помощников.
- 6 помощников с описанием, навыками и примерами запросов.
- Библиотека из 18 промптов с фильтрами, поиском и избранным.
- Диалоги: сценарные ответы, имитация streaming, остановка, повтор, альтернативный вариант, копирование, сохранение ответа, оценка.
- История, глобальный поиск, переименование, удаление, экспорт Markdown.
- Избранное: диалоги, ответы, промпты.
- Вложения-заглушки: имя/размер/тип, без чтения содержимого.
- Настройки: тема, шрифт, плотность, профиль, помощник по умолчанию, Enter, история, streaming, демонстрационная ошибка, экспорт/импорт JSON, очистка, сброс.
- Мобильное меню, адаптивность 320–1440px, пустые состояния, ошибки, поврежденное/недоступное хранилище.
- README обновлён под текущий корень.

## Что осталось непроверенным / ограничения

- Реальный backend/inference не подключался: ответы сценарные.
- GitHub Pages после пуша не проверялся; локальный статический сервер проверен.
- Кроссбраузерность Safari/Firefox не проверялась; использован Chromium.
- Настоящие файлы не читаются и не анализируются — это явно обозначено в UI.
- Реальная синхронизация между устройствами отсутствует; только localStorage текущего браузера.
- Нагрузочное тестирование и долгая история не проводились; есть ограничение импорта и ориентир хранилища.

## Дополнение: переиспользование решений из `site/`

**Дата:** 2026-11-06

**Задача:** найти в старом проекте `site/` полезные интерфейсные решения и перенести их в новое корневое демо, не меняя сам `site/`.

Перенесены и адаптированы:

- `site/assets/js/landing.js` + `.site-header.scrolled` из `site/assets/css/main.css` → тень и более плотная граница шапки при прокрутке. В новом демо слушатель повешен на `#main-content`, потому что прокручивается основная область, а не `window`.
- `IntersectionObserver` для `.reveal → .in` из `landing.js` → плавное появление карточек помощников, промптов и разделов настроек. Скрытое состояние включается только классом `.js`, отключается при `prefers-reduced-motion` и при отсутствии `IntersectionObserver`.
- FAQ-аккордеон `.faq-q / .faq-a / .pm` из `landing.js` и `main.css` → блок «Вопросы о демо» в окне «Как работает демо». Один открытый пункт, анимация `max-height`, поворот «+», `aria-expanded`, `aria-controls` и `aria-hidden`.
- Sticky-навигация и якорные переходы старого сайта → подсветка активного раздела настроек (`.settings-nav a.active`, `aria-current="location"`) с учётом прокрутки до конца страницы.
- `site/assets/js/theme.js` → кнопка темы в шапке получила `aria-pressed`, понятный `aria-label` и синхронизацию после переключения из любого места.

Файлы изменения: `index.html`, `demo.css`, `demo.js`. `site/` не изменялся.

Проверено после переноса:

- 45 функциональных проверок — успешно.
- 65 расширенных проверок — успешно.
- 23 новые проверки перенесённых приёмов — успешно: reveal, тень шапки, состояние кнопки темы, scrollspy настроек, FAQ, reduced motion, отсутствие JS-ошибок.
- axe-core: 0 нарушений на основных экранах в светлой и тёмной теме, в окнах about/search и в about с открытым FAQ.
- Визуальный smoke: ошибок страницы нет, внешних запросов нет.
- `node --check`, CSS-скобки, `[hidden]`, отсутствие маркеров конфликта, `git diff --check` — успешно.
